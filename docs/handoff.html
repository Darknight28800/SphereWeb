3. Installation sur le nouveau poste

Prérequis

  • Node.js ≥ 20 (le poste actuel : v24.20, npm 11). Vérifier : node -v
  • Git, un éditeur (VS Code conseillé)

Étapes

# 1. Récupérer le code
git clone https://github.com/Darknight28800/SphereWeb.git
cd SphereWeb
# (ou, si déjà cloné : git pull)

# 2. Installer les dépendances (lit package.json — rien à la main)
npm install

# 3. Configurer l'e-mail du formulaire de contact
cp .env.example .env.local
#    puis renseigner le vrai mot de passe SMTP dans .env.local

# 4. Lancer le serveur de dev
npm run dev            # http://localhost:3000

Scripts

CommandeEffet
npm run devServeur de développement (port 3000)
npm run buildBuild de production (.next/)
npm run startSert le build
npm run lintESLint (next lint)
npm run iconsRégénère public/ (favicons + og-image.png) via sharp
⚠️ Piège connu. Ne jamais lancer npm run build pendant que npm run dev tourne : les deux partagent .next/ et le build échoue (PageNotFoundError /_error). Arrêter le dev avant de builder. En cas de souci : rm -rf .next puis rebuild.

Dépendances (déjà dans package.json, installées par npm install)

Runtime : next, react, react-dom, framer-motion, nodemailer, zod.
Dev : typescript, tailwindcss, postcss, autoprefixer, eslint, eslint-config-next, sharp, @types/*.
Rien d'autre à installer globalement.

Marque / contenu légal

  • Mentions légales : SIRET 10673178900017, TVA franchise en base (art. 293 B CGI), siège Eure-et-Loir.

Direction visuelle « liquid glass »

  • Panneaux verre dépoli (.glass*), halos diffus (.aura), palette fond #050B2B, voix monospace (nav, libellés de section indexés, méta, boutons).
  • Trame « blueprint » de fond supprimée ; sections claires bannies.

Animations

  • Intro cinématique « hyper-espace » (components/IntroLoader.tsx) au 1ᵉʳ chargement de session — canvas, 6 phases (~12,5 s), bouton « Passer », coupée si prefers-reduced-motion. Durées dans l'objet PHASE.
  • Sphère du hero (HeroSphere.tsx) : rotation 35 s + battement zoom/dézoom + halo pulsé (cycle 6 s).
  • Champ de particules (ParticleField.tsx) : ~64 étoiles qui dérivent, repoussées par le curseur.
  • framer-motion : Reveal.tsx (fondu bidirectionnel apparition/disparition au scroll, subtil), Stagger.tsx (cascade + hover sur les grilles), app/template.tsx (transition de page).
  • Jet de lumière global (CardBeam.tsx) : un faisceau diagonal balaye l'écran (~10 s) puis pause 6 s, visible uniquement sur les panneaux, s'estompe au survol.
